# Автоматизация работы с PostgreSQL на Python

Комплекс скриптов на Python для подключения к базе данных PostgreSQL, создания таблиц, записи данных и выполнения различных выборок.

---

## 📄 Скрипт 1: Исходная работа (app.py)
Скрипт выполняет первоначальное подключение к PostgreSQL, инициализирует структуру базы данных и сохраняет обработанные записи.

## 📄 Скрипт 3: Выборка трех столбцов (app3.py)

## 📄 Скрипт 4: Фильтрация и сортировка данных (app4.py)
Скрипт выполняет комплексный анализ аудиозаписей в базе данных, используя операторы фильтрации **`WHERE`** (по году, длительности и исполнителю) и оператор сортировки **`ORDER BY`** для упорядочивания треков по названию.
